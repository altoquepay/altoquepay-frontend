# altoquepay-frontend

Web frontend of **AlToquePay**, an application for small businesses to manage credit sales, customers and payments.

## Tech stack

- Angular 22 (standalone components, SCSS, routing)
- TypeScript
- npm

## Getting started

Prerequisites: Node.js and npm.

```bash
npm install
npm start
```

The app is served at `http://localhost:4200/` and reloads on file changes.

| Command         | Description                     |
| --------------- | ------------------------------- |
| `npm start`     | Start the development server    |
| `npm run build` | Create a production build       |
| `npm test`      | Run the unit tests              |
